PDF 转 Word 公文格式转换器（Win7&Win10 兼容版）—— 使用说明
=============================================================

【版本说明】
- 运行时：Python 3.8.10（32 位）+ PySide2 5.15.2（Qt 5.15，最后支持 Win7 的版本）
- 单文件 EXE，自带全部运行库，无需安装 Python
- 32 位程序，兼容 Win7 SP1（32/64 位）与 Win10/Win11
- OCR：内置 RapidOCR（PP-OCR 模型），纯本地离线，无需联网

【到货自检三步（建议先做）】
1. 双击 "PDF转Word公文版-win7.exe" → 应弹出主窗口（标题含图标）。
2. 点击"添加 PDF"选择一个文本型 PDF → 点"开始转换" → 打开输出目录查看 docx。
3. （可选）命令行自检：把本目录放入 PATH 或直接在地址栏输入 cmd 后执行
   PDF转Word公文版-win7.exe --out 输出目录 某文件.pdf
   成功会在输出目录生成 docx 与"转换日志.txt"。

【图形界面操作】
1. 点击"添加 PDF"或把 PDF 拖入窗口（支持批量多选）；
2. 设置输出目录（默认：源文件旁 converted 文件夹）；
3. 勾选"转换后应用公文格式（GB/T 9704-2012）"（默认开启）；
4. 点"开始转换"；完成后进度条自动复位，汇总结果显示在下方。
   格式参数可通过"格式参数设置…"自定义（保存在 config.json）。

【公文格式默认参数（GB/T 9704-2012）】
- 页面：A4；页边距 上3.7 / 下3.5 / 左2.8 / 右2.6 cm
- 大标题：二号 方正小标宋简体，居中
- 正文：三号 仿宋_GB2312，两端对齐，首行缩进 2 字符，行距固定值 28 磅
- 层次标题：一、→黑体三号；（一）→楷体_GB2312三号；1. →仿宋加粗
- 落款：文末单位/日期自动右对齐、右空二字
- 数字与英文：Times New Roman；表格：仿宋小四居中

【扫描版 PDF】
自动检测无可提取文字的 PDF 并启用 OCR（速度较慢，约每页 2~5 秒，属正常）。
OCR 结果为纯文字版式（不含表格线还原）。

【Win7 注意事项】
1. 必须已安装 SP1（未装 SP1 的 Win7 无法运行 Python 3.8 运行时）。
2. 若双击无反应或被拦截：右键 EXE → 属性 → 勾选"解除锁定"后再试。
3. VC++ 运行库已直接打包进 EXE（msvcp140/vcruntime140），一般无需额外安装；
   若极少数精简系统仍报缺少 DLL，安装 Microsoft VC++ 2015-2019 运行库
   （x86 版本，微软官网可下载）即可。
4. OCR 引擎已降级为 onnxruntime 1.14.1（官方自 1.15.0 起放弃 Win7 支持，
   1.14.1 为最后兼容版本）。若个别系统扫描件转换仍报
   "DLL load failed while importing onnxruntime"，需确认系统已打齐
   SP1 补丁与通用运行库（KB2999226，一般 Windows Update 已自动安装）。

【常见问题】
1. 提示"文件被占用"：关闭 Word/WPS 中打开的同名文档后重试。
2. 双击后长时间无窗口（本机开发环境曾复现该现象，与个别安全软件向
   32 位进程注入钩子、与 Qt 5.15.2 初始化冲突有关）：
   - 先临时退出安全软件（如 360/管家类）再双击试一次；
   - 若仍不行，改用命令行模式（核心转换功能已充分验证可用）。
3. 复杂跨页表格转换错位：pdf2docx 还原能力有限，可在 Word/WPS 中手动微调。
4. OCR 首次加载模型需数秒，属正常。
5. 扫描件转换报错但文字型正常：多为 OCR 引擎依赖库问题，把报错窗口拍照反馈。
